# LEESIR - A Unified Multi-System Emulator

This repository supports the University of Portsmouth Individual Project **A Unified Multi-System Emulator (LEESIR)**.

## Complete opcode reference

The complete opcode tables used by the project are available here:

**[LEESIR Opcode Reference](./LEESIR-Opcode-Reference/README.md)**

The reference contains:

- Game Boy base opcode table
- Game Boy CB-prefixed opcode table
- NES official opcode table
- C# implementation notes and source mapping

The dissertation contains 20 representative Game Boy and 20 representative NES opcodes; this repository provides the complete supporting tables for examiner access.
